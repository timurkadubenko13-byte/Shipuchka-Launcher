# SHIPUCHKA LOADER

Официальный репозиторий системы обновлений SHIPUCHKA CLIENT.

- Minecraft: 1.21.4
- Mod loader: Fabric
- Client runtime: Java 21
- Release channel: stable

## Как устроены обновления

Лоудер читает файл [latest.json](./latest.json) из основной ветки и проверяет поле `published`.

Когда релиз опубликован:
1. Соберите клиентский JAR из проверенного исходного проекта.
2. Создайте GitHub Release с тегом версии, например `v2.0.1`.
3. Прикрепите JAR как отдельный release asset.
4. Посчитайте SHA-256 именно опубликованного JAR.
5. Обновите `latest.json`: укажите версию, прямую ссылку на asset и SHA-256.
6. Установщик должен проверить SHA-256 до установки и не заменять файл при несовпадении.

## Безопасность

- Не добавляйте GitHub Personal Access Token, пароли или приватные ключи в исходники, JAR, EXE или этот репозиторий.
- Не публикуйте исходный код клиента в этом репозитории релизов.
- Не запускайте установку, если SHA-256 не совпадает.
- Не удаляйте старый рабочий JAR до успешной проверки нового файла.
- Для приватных ключей публикации используйте GitHub Actions Secrets, если позже автоматизируете сборку.
