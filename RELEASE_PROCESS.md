# Публикация релиза SHIPUCHKA CLIENT

## Перед публикацией
- [ ] Сборка выполнена на JDK 21.
- [ ] Проверен запуск Minecraft 1.21.4 + Fabric.
- [ ] JAR протестирован в чистом профиле.
- [ ] Версия в `gradle.properties` совпадает с тегом релиза.
- [ ] В релиз не попали токены, пароли или приватные файлы.

## Создание GitHub Release
1. Откройте вкладку Releases репозитория.
2. Нажмите Draft a new release.
3. Создайте тег вида `vX.Y.Z` (например, `v2.0.1`).
4. Прикрепите собранный `shipuchka-client-<version>.jar`.
5. Опубликуйте релиз.

## Обновление latest.json
После публикации:
1. Скопируйте прямую ссылку на JAR asset из GitHub Release.
2. Рассчитайте SHA-256 файла, например в PowerShell:
   `Get-FileHash .\shipuchka-client.jar -Algorithm SHA256`
3. Измените `published` на `true`.
4. Заполните `version`, `assetName`, `downloadUrl`, `sha256`, `releaseUrl` и `releaseNotes`.
5. Сохраните файл в основной ветке.

Лоудер должен считать обновление доступным только если `published=true`, версия корректна, URL использует HTTPS, а SHA-256 состоит ровно из 64 шестнадцатеричных символов. После скачивания он обязан проверить хеш до установки.
